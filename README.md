 Group Project – Event / Resource Management System
📌 Overvi

A collaborative application designed to manage and organize campus facilities and resources efficiently. The system allows users to browse, search, and manage available resources such as lecture halls, laboratories, meeting rooms, and equipment.

🧑‍💻 My Contribution – Resource Management Module
🏢 Facilities & Assets Catalogue
Developed a complete catalogue system for campus resources including:
Lecture halls
Laboratories
Meeting rooms
Equipment
Enabled users to view all available resources with structured and detailed information.
🔍 Search & Filtering System
Implemented advanced search and filtering functionality based on:
Resource type
Capacity
Location
Availability status
🛠️ Admin Management Panel
Built administrative features to manage resources:
Add new resources
Edit existing resources
Update resource details
Deactivate or remove resources
📊 Resource Data Model

Each resource includes:

Type (Lecture Hall / Lab / Equipment etc.)
Location
Capacity
Availability windows
Operational status:
ACTIVE
OUT_OF_SERVICE
INACTIVE

Modular resource management system
